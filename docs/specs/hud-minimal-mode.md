# 桌面悬浮窗极简模式

## Goal

当前桌面悬浮窗（HUD）仅有一种标准布局，展示两市总成交、四大核心指数、完整自选股列表及顶部与底部共约 8–10 个控制按钮，在长时间盯盘或与其他桌面软件同屏使用时占用屏幕面积较大、视觉元素偏多。

完成后，用户可将桌面悬浮窗一键切换为「极简模式」，显著缩小窗体尺寸，只保留「沪深两市总成交 + 最多 3 条自选股」，并隐藏大部分按钮，同时仍可通过系统托盘、设置面板、老板键和点击行完成常用操作。

## Behavior

**模式切换与持久化**
- HUD 支持「标准模式」（默认）与「极简模式」，当前模式持久化保存到本地配置，应用重启后自动恢复。
- 支持三处实时同步切换：
  - HUD 顶部操作区：标准模式展示「简」按钮切入极简模式；极简模式仅保留「标准」按钮切回标准模式。
  - 系统托盘右键菜单：提供「极简模式」复选菜单项。
  - 详情浮层设置页：提供「悬浮窗展示模式」（标准模式 / 极简模式）分段开关。

**极简模式内容展示**
- 仅展示 1 块「沪深总成交」（继续按 `000001.SH + 399106.SZ` 口径，展示累计成交额、较昨日同期百分比、放/平/缩量状态及边际斜率趋势；数据缺失或延迟时显式显示 `降级/无数据`、`陈旧` 或 `降级` 标识，绝不补零）。
- 紧随其后展示按当前自选股排序取前 3 条的个股行（每条展示名称、现价、涨跌幅、成交额与放/平/缩量或降级状态）。
- 自选股不足 3 条时按实际条数展示；为 0 条时展示 1 行「暂无自选股，点击添加」（点击打开详情浮层的自选股页签）；超过 3 条时仅展示前 3 条，不显示滚动条。
- 点击「沪深总成交」或任意个股行仍可打开对应标的的详情浮层分时对比图。

**隐藏元素与保留能力**
- 极简模式下隐藏：四大核心指数区块、自选股折叠栏与「+ 管理」按钮、底部状态栏（数据源/延迟/更新时间/透明度滑块/老板键说明/刷新/设置/开发测试按钮）、顶部「置顶 / 静音 / 详情 / 关闭隐藏」按钮。
- 极简模式下保留：顶部紧凑拖拽区（含状态圆点、异常/回放/复盘标识与唯一的「标准」切回按钮）、窗口置顶与透明度设置、老板键一键显隐、告警触发时的呼吸边框高亮、提示音与 Windows 原生通知（告警横幅底部叠加展示，不挤出第 3 条个股）。

**窗体尺寸自适应**
- 切入极简模式时悬浮窗实际物理尺寸同步缩小（不留透明空白占位遮挡底层窗口），切回标准模式时恢复标准尺寸。
- 缩放时若悬浮窗位于屏幕右半侧则保持右边缘对齐，位于左半侧则保持左边缘对齐，并确保缩放后窗体完整留在当前显示器工作区内。

## Constraints

- 遵循项目硬不变量：沪深总成交额严格为 `000001.SH + 399106.SZ`（不含北证），严格红涨绿跌，数据缺失显式降级不补零。
- 保持 Electron 进程隔离（`contextIsolation: true`、`nodeIntegration: false`），通过类型安全 preload IPC 同步外壳状态，配置写入本地 SQLite `app_settings`。
- 默认模式保持为标准模式，确保升级后不破坏已有用户界面预期。

## Out of Scope

- 单独维护一套独立于自选股排序的「极简选股清单」或自定义极简显示条数。
- 悬浮窗自由拖拽边框调整大小、单行跑马灯模式或多 HUD 窗口实例。
- 修改核心放缩量/斜率计算公式或行情轮询频率策略。

## Acceptance Criteria

- 可在 HUD 顶部按钮、系统托盘菜单与详情设置页三处切换标准/极简模式且状态实时同步；重启应用后恢复上次所选模式。
- 极简模式下 HUD 仅展示沪深总成交与最多 3 条自选股（0 条展示添加引导，超过 3 条仅取前 3 条），四大指数、底部状态栏、自选管理栏及顶部非切换按钮均隐藏，仅保留 1 个「标准」切换按钮。
- 切换模式时 HUD 物理窗口尺寸真实缩放且不越出当前显示器工作区；点击总成交或个股行可正常打开详情浮层，告警呼吸高亮与提示音照常生效。
- 数据缺失或陈旧时极简模式显式展示降级/陈旧标识且不对缺失金额补零。
- `npm run typecheck`、`npm run test`、`npm run build` 全部通过，且覆盖设置持久化、缩放几何锚点、WindowManager 缩放顺序、托盘菜单及极简 HUD 渲染断言。
