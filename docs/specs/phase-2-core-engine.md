# Phase 2：纯 TypeScript 核心领域引擎

## Goal

项目还没有任何金融计算逻辑：交易时间轴、午休折叠、两市总成交额聚合、放/缩量判定、斜率与快速异动告警都尚未实现。

完成后，`src/core/` 提供一套不依赖网络、UI、Electron 的确定性引擎，输入分钟数据与快照即可得到每个标的的能量状态与告警事件，并由单元测试锁定全部边界行为。

## Behavior

**交易时钟**
- 给定时间戳与交易日历，返回市场阶段：`PRE_MARKET`、`OPEN_AUCTION`（09:15–09:25）、`AUCTION_GAP`（09:25–09:30）、`MORNING_SESSION`、`LUNCH_BREAK`、`AFTERNOON_SESSION`、`POST_MARKET`、`CLOSED_DAY`（非交易日）。
- 时间戳 ↔ `minuteIndex`（0..239）双向映射，规则见 `docs/PLAN.md` §2.2：`11:30` 归入 119，`15:00` 归入 239，午休不产生索引。

**大盘聚合**
- 由 `000001.SH` 与 `399106.SZ` 合成 `MARKET_TOTAL`。
- 任一侧缺失或两侧分钟未对齐时，`MARKET_TOTAL` 标记为 `degraded` 且不输出合计值，不得用单边数据冒充全市场。
- `399001.SZ`、`399006.SZ`、`000688.SH` 永不参与合计。

**能量计算**（公式以 `docs/PLAN.md` §2.3 为唯一来源）
- 对大盘聚合、四大指数和任意个股一视同仁地计算：$\Delta A(t)$、$R(t)$、全天预测 $\hat{A}_{\text{full}}(t)$、放/平/缩量状态、OLS 滚动斜率 $S_W(t)$、区间增量倍数 $M_W(t)$。
- 盘中未闭合分钟按已过秒数对昨日同期做线性插值，避免分钟初的锯齿误判。
- 窗口 $W$ 只在折叠后的连续 `minuteIndex` 上取值，跨午休时 `11:28→13:02` 视为连续分钟。
- 无法计算时输出“不可用”而不是 0：昨日同期缺失或 $A_{\text{prev}}(t) \le 0$ 时 $R$ / 预测 / 状态不可用；$M_W$ 分母 ≤ 0 时不可用；窗口内点数不足时 $S_W$ 不可用；无昨日全天成交额时不输出全天预测。
- `09:25` 开盘竞价作为独立锚点，不进入斜率窗口。

**告警判定**
- `minuteIndex < 5` 不触发。
- 快速放量 / 快速缩量按 §2.3 默认阈值判定，支持「且 / 或」模式（默认「且」）。
- 全局默认参数可被单个标的覆写（阈值、窗口、开关）。
- 同一 `(symbol, direction)` 触发后进入冷却（默认 5 分钟），冷却内不再产生事件；相反方向不受冷却影响，可立即触发。
- 任一指标“不可用”时不触发。

## Constraints

- `src/core/` 不得 import Electron、DOM、`node:*` 网络/文件模块或任何 IO。
- 当前时间、交易日历、阈值均由调用方传入，引擎内不读取系统时钟，结果完全可复现。
- 所有时间按北京时间（Asia/Shanghai）解释，与宿主机时区无关。
- 金额单位统一为人民币元（`number`）。

## Out of Scope

- 数据采集、持久化、IPC 推送。
- 通知、提示音、呼吸高亮等告警通道。
- 金额的 UI 格式化（`万亿 / 亿 / 万`）。

## Acceptance Criteria

`tests/core/` 下 vitest 全部通过，且至少覆盖：
- 时钟：`09:15`、`09:25`、`09:30`、`11:29`、`11:30`、`12:00`、`13:00`、`14:59`、`15:00`、`15:01` 的阶段与 `minuteIndex`；非交易日返回 `CLOSED_DAY`。
- `000001.SH + 399106.SZ` 正确合计；其他指数不被累加；单边缺失时 `degraded` 且无合计值。
- 已知输入下 $\Delta A$、$R$、预测、状态、$S_W$、$M_W$ 与手算结果一致；`±5%` 边界值落在正确状态。
- 未闭合分钟第 10 秒时，插值后不出现骤缩误判。
- `11:28→13:02` 滚动斜率连续，午休不计入窗口。
- 昨日同期缺失 / 为 0 时各指标为“不可用”且不触发告警。
- `09:30–09:34` 满足阈值也不触发；`09:35` 起可触发。
- 冷却期内同方向不重复触发、冷却结束后可再次触发、反方向即时触发；单股覆写阈值生效。
- `npm run typecheck` 通过。
