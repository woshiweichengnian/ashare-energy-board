# Phase 4：Electron 桌面外壳与告警通道

## Goal

数据和计算已在主进程运行，但用户还没有可用的桌面形态：没有悬浮 HUD、详情浮层、托盘、老板键，告警事件也不会到达用户。

完成后，用户获得一个置顶半透明悬浮窗 + 可展开的详情浮层 + 系统托盘，可一键显隐，快速放/缩量告警通过事件落库、Windows 通知、HUD 呼吸高亮和提示音同步送达。

## Behavior

**紧凑 HUD 窗口**
- 无边框、透明圆角、始终置顶、不占任务栏；通过自定义拖拽区移动。
- 记住上次屏幕位置与透明度（30%–100%），重启后恢复；保存的位置超出当前屏幕时回到可见区域。
- 此阶段 HUD 内容可为简版（至少显示两市总成交额与数据状态），完整视觉在 Phase 5。

**详情浮层窗口**
- 点击 HUD 展开按钮或点击某个标的时打开，贴近 HUD 显示，空间不足时屏幕居中。
- 失焦不销毁；按 `Esc` 或点击收起按钮隐藏。

**系统托盘**
- 右键菜单：显示/隐藏悬浮窗、展开详情、置顶开关、静音开关、手动刷新、开机自启开关、打开设置、退出。
- 悬停 Tooltip 显示两市总成交额与放/平/缩量状态；数据降级时明确显示降级。
- 关闭窗口只隐藏到托盘，只有“退出”真正结束应用。

**全局老板键**
- 默认 `Alt+Shift+A`，一键隐藏 / 恢复所有窗口（恢复到隐藏前状态）。
- 注册失败（被占用）时给出冲突提示；主进程支持运行时改绑（设置界面在 Phase 5）。

**告警通道**
- 收到核心引擎产生的告警事件后依次：写入 `alert_events` → 发送 Windows 原生通知（标的名、方向、斜率、区间倍数）→ 经 IPC 通知 HUD 呼吸高亮并播放提示音。
- 急放与急缩使用可区分的提示音；静音时不发声，其余通道照常。
- 提供开发用“模拟告警”入口，以便本地验证全链路；模拟事件需明确标记为测试，不得伪装成实盘告警。

## Constraints

- 窗口、托盘、老板键、通知、写库全部在 `src/main/`；提示音与呼吸效果在渲染进程，经 preload 类型化 API 触发。
- 保持 `contextIsolation: true`、`nodeIntegration: false`。
- 窗口位置、透明度、静音、置顶、老板键等设置存入 `app_settings`。
- 红涨绿跌：急放用红色、急缩用绿色。

## Out of Scope

- HUD 完整信息布局、ECharts 图表、自选股管理、事件流、设置面板 UI（Phase 5）。
- 外部 Webhook 推送。
- 多显示器布局策略之外的窗口管理（如吸附、多 HUD 实例）。

## Acceptance Criteria

Windows 本机人工验证：
- HUD 可拖拽、置顶、半透明，不出现在任务栏；重启后位置与透明度恢复。
- 点击 HUD 打开详情浮层，`Esc` 可收起，失焦后仍保留。
- 托盘菜单各项可用；Tooltip 显示总成交额与状态；关闭窗口后应用仍在托盘运行。
- 老板键一键隐藏 / 恢复所有窗口；快捷键被占用时出现冲突提示。
- 触发模拟告警：`alert_events` 新增记录、Windows 通知弹出、HUD 呼吸高亮、播放对应提示音；开启静音后不发声但其他通道照常。
- `npm run typecheck`、`npm run test` 通过。
