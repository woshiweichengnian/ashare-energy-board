# Phase 5：HUD 与详情看板界面

## Goal

桌面外壳和告警通道已可用，但 HUD 只有简版内容，详情浮层没有图表，用户也无法在软件内管理自选股、查看异动历史或调整参数。

完成后，用户在 HUD 上一眼看到大盘、四大指数与自选股的能量状态，在详情浮层里查看今昨分时能量对比图、管理自选股、回看今日异动、修改全部设置，且所有配置重启后保留。

## Behavior

**紧凑 HUD**
- Hero 区：沪深两市总成交额、较昨日同期（百分比与差额，如 `+12.4% / +842亿`）、预测全天成交额、趋势斜率箭头（急放红脉冲 / 急缩绿脉冲）。
- 四大指数行：上证指数、深证成指、创业板指、科创50 的点位、涨跌幅、成交额、`全市场` / `成分股` 口径角标、放/平/缩量徽章。
- 自选股列表（可滚动 / 折叠）：名称/代码、现价、涨跌幅、成交额、放/平/缩量徽章。
- 底部状态条：数据源、最近更新时间、延迟 / 降级提示，以及静音、透明度、展开详情快捷按钮。
- 金额按量级格式化（`万亿 / 亿 / 万`）。

**详情浮层**
- 分时能量对比图（上下联动）：
  - 上图：今日累计成交额实线 vs 昨日同期累计虚线，放量区淡红、缩量区淡绿填充；右轴叠加指数点位或个股分时价；标出 `09:25` 竞价锚点；午休无缝折叠。
  - 下图：今昨 1 分钟增量对比柱、滚动边际量比偏离曲线（Tooltip 与告警同步展示边际趋势斜率）、异动触发散点。
  - 可切换查看大盘聚合、任一指数或任一自选股。
- 自选股面板：按代码或中文名搜索（同花顺优先，公开源兜底）并添加；删除；拖拽或上下调整排序；单股提醒开关与自定义阈值弹窗。
- 今日异动事件流：按时间倒序列出快速放量 / 缩量记录，点击切换到对应标的图表。
- 设置面板：刷新周期（3–15 秒）、放/平/缩阈值、斜率窗口（3/5/10 分钟）、急放/急缩阈值与「且/或」模式、冷却分钟数、老板键改绑（冲突提示）、HUD 透明度、提示音开关、同花顺 Key 输入与连接测试（保存后只显示“已配置”及来源）、本地数据库留存统计。

**降级显示**
- 任何数据缺失、过期或降级时，相关数值显示为明确的降级 / 无数据状态，不显示 0 或旧值冒充实时值。

## Constraints

- 渲染进程只通过 preload 类型化 API 读写数据，不直接访问网络、数据库或 Key。
- 红涨绿跌；暗色半透明磨砂 HUD 风格。
- 设置修改即时作用于主进程调度与告警，无需重启。
- Key 一旦保存，界面不再回显明文。

## Out of Scope

- 新的计算指标或告警类型。
- 外部 Webhook、多账户、云同步。
- 浏览器 Web 页面版本。
- 主题切换 / 亮色模式。

## Acceptance Criteria

- HUD 与详情浮层切换流畅；图表在默认刷新周期下持续更新 30 分钟无闪烁、渲染进程内存无持续增长（复用图表实例增量更新）。
- 自选股增、删、排序、单股阈值修改后重启应用仍保留，并在下一轮轮询中生效。
- 修改刷新周期、阈值、窗口、冷却后，主进程行为随之变化，重启后保留。
- 输入并保存同花顺 Key 后连接测试成功；重启后显示“已配置”，界面、日志与数据库明文中均找不到 Key。
- 点击事件流记录可跳转到对应标的图表。
- 断开网络或注入数据缺失时，HUD 与图表显示降级状态而非 0。
- 涨为红、跌为绿，全界面一致。
- `npm run typecheck`、`npm run test` 通过。
